# TCC Community v12 — Privacy & Safety

Adds member-controlled privacy settings for directory visibility, connection requests, private messages, and online presence.

## Supabase
Run `supabase/community_privacy_v12.sql` after `community_profile_v11.sql`.

## Controls
- Appear in member directory
- Allow connection requests
- Allow private messages
- Show online status

The server API enforces these controls; they are not merely UI settings.
